# Почерк — буквы

Android-приложение (и веб-версия) для сбора рукописных глифов с телефона.
Вы рисуете каждый символ пальцем по несколько раз, а приложение само
нумерует варианты, сохраняет результат после каждого экрана и в конце
экспортирует всё одним ZIP-архивом в том же формате JSON, что и редактор
Cursive Glyph Editor (ключевой HTML).

Вся работа идёт на устройстве, сеть не нужна.

## Что нужно собрать

151 символ, по умолчанию **4 варианта каждого** (минимум; в настройках можно
поставить 4–8) — всего 604 глифа:

| Группа | Символы |
|---|---|
| Русские строчные | абвгдеёжзийклмнопрстуфхцчшщъыьэюя (33) |
| Русские заглавные | АБВГДЕЁЖЗИЙКЛМНОПРСТУФХЦЧШЩЭЮЯ (33) |
| Английские строчные | a–z (26) |
| Английские заглавные | A–Z (26) |
| Цифры | 0–9 (10) |
| Знаки препинания | `.,:;!?-—()«»"'` (16) |
| Математика и знаки | `=+×*/<>%№` (9) |

Экспорт ZIP открывается только когда заполнены **все** символы.

## Как пользоваться

1. На экране — сетка клеток (по умолчанию 4×3 = 12 клеток). Каждая клетка
   подписана: символ и номер варианта назначаются автоматически, вводить
   их не нужно. Нарисуйте символ одним штрихом прямо в клетке.
2. **«Следующий →»** — сохраняет все клетки экрана (и каждый штрих
   сохраняется сразу) и показывает следующий экран. **«← Назад»** —
   предыдущий экран; нарисованное можно перерисовать в любой момент.
3. Кнопка **✕** на клетке очищает только её, **«Очистить экран»** — все
   клетки текущего экрана.
4. Кнопка **✎** на заполненной клетке открывает редактор точек
   входа/выхода (как «Зафиксировать» в HTML-редакторе): точки перетаскиваются
   пальцем, вводятся координатами или сдвигаются стрелками.
   Кнопка **⬇** на клетке скачивает один JSON этой буквы (то же имя и формат,
   что в ZIP) — удобно для проверки функциональности и формата.
5. **«Обзор»** — карта заполненности: по каждому символу видно, сколько
   вариантов нарисовано (●●○○). Тап по символу переносит к его первому
   незаполненному варианту — так удобно возвращаться и доделывать пропуски.
6. Когда все символы заполнены, кнопка **«Экспорт ZIP»** становится активной
   и скачивает/расшаривает `pocherk-glyphs.zip`.

### Принципы работы (как в HTML-редакторе)

- Один штрих на символ. Штрих сглаживается скользящим средним по трём точкам.
- Точки входа/выхода определяются автоматически: вход — начало штриха,
  выход — конец; ручные точки (handle) — на 15% и 85% пути.
- Штрих короче 6 сырых точек отбрасывается как слишком короткий.
- Логический холст всегда 600×600, направляющие: верхняя линия на 20%
  высоты, базовая на 70%, сетка поля.

### Настройки (⚙)

- **Размер клетки, мм** — реальный масштаб, минимум 5 мм (по умолчанию 5;
  поле всегда 3×3 клетки, при 5 мм это 15×15 мм). Увеличивается только вверх —
  клетки становятся крупнее. Меняется только физическое отображение,
  сохранённые координаты не пересчитываются. Направляющие (сетка 3×3,
  верхняя и базовая линии) всегда видны: их толщина задаётся в экранных
  пикселях, а не в логических единицах холста.
- **Клеток на экране** — столбцы и строки (по умолчанию 4×3): чем больше,
  тем реже нужно нажимать «Следующий».
- **Толщина штриха**, **направляющие вкл/выкл**, **число вариантов** (от 4).
- **«Сбросить всё»** — удалить все глифы и начать сначала.

Данные хранятся в IndexedDB на устройстве и переживают перезапуск
приложения и его обновление (при той же подписи APK).

## Формат экспорта

ZIP содержит:

```
symbols/а_1.json            по одному JSON на вариант каждого символа
symbols/загл_а_1.json
symbols/lat_a_1.json
symbols/lat_upper_a_1.json
symbols/digit_5_1.json
symbols/точка_1.json         знаки — по имени знака
manifest.json                список всех файлов: символ, вариант, группа
README.txt                   описание формата
```

Каждый JSON — в точности формат HTML-редактора:

```json
{
  "char": "б",
  "metrics": { "topLineY": 120, "baselineY": 420, "canvasWidth": 600, "canvasHeight": 600 },
  "path": [ { "x": 10.5, "y": 20.1 } ],
  "anchors": {
    "entry": { "main": { "x": 0, "y": 0 }, "handle": { "x": 0, "y": 0 } },
    "exit":  { "main": { "x": 0, "y": 0 }, "handle": { "x": 0, "y": 0 } }
  }
}
```

### Стандартизированная нумерация имён файлов

Номер варианта — целое число после последнего подчёркивания, без ведущих
нулей. Имена безопасны для ZIP/Windows/Android (нет символов `\/:*?"<>|`)
и однозначно парсятся обратно в символ и вариант:

| Символ | Имя файла |
|---|---|
| русские строчные | `а_1.json` |
| русские заглавные | `загл_а_1.json` |
| английские строчные | `lat_a_1.json` |
| английские заглавные | `lat_upper_a_1.json` |
| цифры | `digit_5_1.json` |
| знаки | `<имя>_1.json`, например `точка_1.json`, `запятая_2.json`, `левая_ёлочка_1.json` |

## Сборка

**Веб-версия (для проверки на компьютере/телефоне):**

```bash
npm install
npm run dev       # http://localhost:5173
```

**Android APK:** собирается в GitHub Actions (`.github/workflows/android.yml`):
веб-сборка → `npx cap add android` → Gradle. Готовый APK — в артефактах
Actions, а при настроенной подписи — в Releases.

### Подпись Android

Для обновлений поверх установленной версии нужен один постоянный ключ.
Положите его в секреты репозитория (Settings → Secrets and variables → Actions):
`ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`,
`ANDROID_KEY_PASSWORD`. Создать ключ один раз:

```bash
keytool -genkeypair -v -keystore pocherk-release.jks -storetype JKS -alias pocherk -keyalg RSA -keysize 2048 -validity 10000
base64 -w0 pocherk-release.jks
```

Без секретов собирается debug APK (для первой установки; поверх APK с другой
подписью не обновится). Версия берётся из `package.json`, versionCode —
из номера запуска Actions.
