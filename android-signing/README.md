# Общий ключ подписи

`pocherk.p12` — постоянный ключ, которым подписываются все обычные сборки APK.

- тип хранилища: PKCS12
- alias: `pocherk`
- пароль хранилища и ключа: `pocherk`
- срок действия сертификата: 30 лет

Зачем ключ лежит в репозитории: Android разрешает устанавливать обновление
поверх приложения только тогда, когда подпись совпадает. Один и тот же ключ
во всех сборках = «просто обновить» без удаления приложения и потери
нарисованных глифов.

Это **не** ключ для Google Play: пароль известен, ключ публичный. Для
публикации в магазине используйте собственный закрытый keystore через
секреты `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`,
`ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD` (они имеют приоритет над этим
файлом, см. README в корне).

Смена ключа означает другую подпись: APK с новым сертификатом не встанет
поверх старого — понадобится один раз удалить приложение.
